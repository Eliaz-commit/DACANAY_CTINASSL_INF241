# AKYAT PH activity
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
User requested MongoDB, Express, React, and Node.js.
## Product Purpose
An actual UI for Activity 1.1 using the user's AKYAT PH capstone concept. Demonstrates viewing, creating, editing, and deleting hiking trips. Separate implementation preserves the existing capstone.
## Users
Design assumption: hiking operators managing scheduled trips.
## Capabilities and Constraints
Responsive trip workspace and trail discovery. Sample records are explicitly identified. MongoDB supports real persistence when configured; a labeled browser demo permits UI review without database setup. Authentication, payments, and real bookings are outside this activity implementation.
## Brand Commitments
Inherit AKYAT PH's existing Cordillera Canopy palette, mountain imagery, and hiking terminology.
