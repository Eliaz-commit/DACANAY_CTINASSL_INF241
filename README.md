# DACANAY CTINASSL INF241

The AKYAT PH MERN application is in [`AKYAT-MERN/`](AKYAT-MERN/). The existing activity PDFs are in [`Dacanay_CTINASSL_Files/`](Dacanay_CTINASSL_Files/).

## Run the application

Open `AKYAT-MERN` in VS Code, then run these commands in its terminal:

```powershell
npm ci
npm run server
```

Keep that terminal open. Open a second terminal in the same folder and run:

```powershell
npm run dev
```

Open http://127.0.0.1:5180. MongoDB must be running for sign-up, login, and trip management. See the [application README](AKYAT-MERN/README.md) for MongoDB and Postman setup.
